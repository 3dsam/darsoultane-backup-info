# Darsoultane Backups

Darsoultane Backups is a personal backup tool operated by Samir.
It uses restic and rclone to store encrypted backups in the
owner’s Google Drive account.

Google Drive access is limited to files created or authorized
for use with this app. This tool is not offered as a public service.
