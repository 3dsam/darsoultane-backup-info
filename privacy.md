# Privacy Policy — Darsoultane Backups

Last updated: November 1, 2026

Darsoultane Backups is a personal backup tool operated by Samir.
It is not offered as a public service.

## Google Drive access and use

The tool uses Google authorization through rclone to create,
read, update, and delete backup files authorized for this app.
It also checks available storage space.

Access is limited by the drive.file permission. Google Drive
data is used only for backup storage, verification, retention,
and recovery.

## Storage and security

Restic encrypts backup contents before uploading them to Google
Drive. Authorization credentials are stored locally on the
operator’s computer, outside the public source repository.

This information website contains no backup files or credentials.

## Sharing

The tool does not sell Google user data or use it for advertising
or AI model training. Encrypted backups are transferred to Google
Drive for storage. Google processes that storage under its own
terms and privacy policy.

## Retention and deletion

Backups remain until removed by the configured retention policy
or by the operator. Access can be revoked through Google Account
security settings. Revoking access does not delete existing
backups; those must be deleted separately.
